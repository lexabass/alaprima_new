# Frontend для Художественной Галереи на Next.js

Этот проект представляет собой frontend, созданный на Next.js, для сайта художественной галереи. Он получает данные из Strapi backend.

---

## Запуск проекта

1.  **Убедитесь, что backend запущен:**
    Ваш Strapi backend должен быть запущен, обычно по адресу `http://localhost:1337`.

2.  **Создайте `.env.local` файл:**
    В корне этого проекта создайте файл `.env.local` и добавьте в него URL вашего Strapi API:
    ```
    STRAPI_API_URL=http://localhost:1337
    ```

3.  **Установите зависимости:**
    ```bash
    npm install
    ```

4.  **Запустите сервер для разработки:**
    ```bash
    npm run dev
    ```

5.  **Откройте приложение:**
    Откройте в браузере [http://localhost:3000](http://localhost:3000), чтобы увидеть результат.

---

## Структура проекта

*   **/src/app/**: Содержит все страницы и маршруты приложения.
*   **/src/components/**: Содержит переиспользуемые React-компоненты.
*   **/src/lib/**: Содержит утилиты для работы со Strapi API (`api.ts`), обработки медиафайлов (`media.ts`) и типы данных (`types.ts`).
*   **next.config.mjs**: Конфигурация Next.js, включая `remotePatterns` для изображений из Strapi.
